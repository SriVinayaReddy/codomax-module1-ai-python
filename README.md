# Introduction to AI & Python

This repository contains my learning notes and Python practice work completed as part of Module 1 of my CODOMAX Internship.
The module focuses on building a foundation in Artificial Intelligence concepts and Python programming fundamentals.

## 📌 Module Overview

**Module:** 1 – Introduction to AI & Python
**Duration:** Day 1 – Day 4
**Level:** Beginner

### Topics Covered

- Artificial Intelligence (AI)
- Machine Learning (ML)
- Deep Learning (DL)
- Real-world applications of AI
- Python fundamentals
- Variables and data types
- Conditional statements
- `for` and `while` loops
- Functions
- Lists and basic list operations
- Beginner Python problem-solving
