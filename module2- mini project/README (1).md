# Python Mini Projects

This folder contains my Python mini-project submissions for Module 2 of my CODOMAX Internship.
Four projects were built, each increasing in complexity, to apply core Python concepts learned in Module 1.

## 📌 Module Overview

**Module:** 2 – Python Mini Project
**Duration:** Day 5 – Day 8
**Level:** Beginner

## 📂 Projects

### 1. Simple Calculator — *Easy*
A basic calculator that performs addition, subtraction, multiplication, and division based on user input, with division-by-zero handling.

**Concepts used:** functions, conditionals, user input, error handling

File: `1_easy_calculator.py`

### 2. Number Guessing Game — *Medium*
The program picks a random number between 1–100, and the user tries to guess it within a limited number of attempts, receiving "too high/too low" hints along the way.

**Concepts used:** `random` module, loops, conditionals, break statements

File: `2_medium_guessing_game.py`

### 3. Student Grade Calculator — *Difficult*
Takes marks for multiple students across multiple subjects, calculates each student's average, assigns a letter grade, and ranks all students from highest to lowest average.

**Concepts used:** nested loops, dictionaries, functions, sorting with `lambda`

File: `3_difficult_student_grade_calculator.py`

### 4. Expense Tracker — *Very Difficult*
A menu-driven console app to add, view, filter, and delete expenses, with data saved permanently to a JSON file so records persist between runs.

**Concepts used:** file handling, JSON, functions, menu-driven program flow, CRUD operations

File: `4_very_difficult_expense_tracker.py`

## ▶️ How to Run

```bash
python 1_easy_calculator.py
python 2_medium_guessing_game.py
python 3_difficult_student_grade_calculator.py
python 4_very_difficult_expense_tracker.py
```
Requires Python 3.x — no external libraries needed (uses only built-in `random`, `json`, and `os` modules).

## 🎯 Learning Outcome

Building these four projects — from a simple calculator to a persistent expense tracker — helped me apply variables, loops, conditionals, functions, dictionaries, and file handling in real, working programs rather than isolated exercises. This hands-on practice strengthens the foundation for more advanced Python and data-driven projects in later modules.
